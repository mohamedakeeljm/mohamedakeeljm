# 🚀 How to Setup Your Premium GitHub Profile README

## 📌 Step 1: Create Your Profile Repository
1. Go to [GitHub](https://github.com/new).
2. In the **Repository name** field, type your **exact GitHub username** (e.g., if your username is `mohamedakeel`, name the repository `mohamedakeel`).
3. You will see a special green box saying:
   > *"You found a secret! `<username>/<username>` is a special repository that you can use to add a `README.md` to your GitHub profile."*
4. Ensure the repository is set to **Public** 🌐.
5. Check **Add a README file** (or push this folder directly).
6. Click **Create repository**.

---

## 📌 Step 2: Add Files
1. Copy the contents of [`README.md`](./README.md) into your profile repository's `README.md`.
2. Replace `mohamedakeel` with your actual GitHub username across the file if your username is different.
3. Update your social links (LinkedIn, Twitter, Portfolio, etc.).

---

## 📌 Step 3: Enable Snake Contribution Animation (Optional but Recommended)
1. Add the [`.github/workflows/snake.yml`](./.github/workflows/snake.yml) file to your repository under `.github/workflows/snake.yml`.
2. Go to **Settings** > **Actions** > **General** in your repository.
3. Under **Workflow permissions**, select **Read and write permissions** and click **Save**.
4. Go to the **Actions** tab, select **Generate Snake Animation**, and click **Run workflow**.
5. Once it completes, your animated snake eating your contributions will display dynamically on your profile!
